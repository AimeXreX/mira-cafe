# منوی دیجیتال میرا کافه

پروژه‌ای سبک، راست‌چین و Mobile First با PHP 8.1 و MySQL/MariaDB. سایت بدون WordPress، Laravel، Node.js یا کتابخانه خارجی اجرا می‌شود.

## امکانات

- منوی سریع و واکنش‌گرا با جست‌وجوی آنی و دسته‌بندی چسبان
- نمایش نام فارسی/انگلیسی، توضیح، قیمت، عکس و وضعیت موجودی
- پنل فارسی برای مدیریت کامل محصولات، دسته‌ها و تنظیمات
- ساخت امن مدیر اولیه، محدودسازی تلاش ورود، CSRF، PDO و خروجی امن
- اعتبارسنجی واقعی تصویر، نام تصادفی و کوچک‌سازی خودکار با GD در صورت فعال بودن
- SEO پایه، Open Graph، favicon، کش فایل‌های ثابت و هدرهای امنیتی

## نیازمندی‌ها

- Apache و PHP نسخه 8.1 یا بالاتر
- MySQL 5.7+ یا MariaDB 10.3+
- افزونه‌های PHP: `pdo_mysql`، `fileinfo` و `mbstring`
- افزونه `gd` اختیاری اما برای کوچک‌سازی تصاویر توصیه می‌شود
- SSL معتبر برای `https://miracafe.ir`

## نصب قدم‌به‌قدم در cPanel

### ۱) آپلود و Extract

1. وارد cPanel شوید و **File Manager** را باز کنید.
2. وارد پوشه `public_html` شوید. اگر دامنه اصلی فایل پیش‌فرضی مانند `index.html` دارد، پس از گرفتن نسخه پشتیبان آن را کنار بگذارید.
3. فایل ZIP پروژه را Upload کنید.
4. روی ZIP کلیک راست و **Extract** را انتخاب کنید.
5. مطمئن شوید `index.php` مستقیماً داخل `public_html` قرار دارد؛ نباید یک پوشه اضافه بین آن‌ها باشد.

ساختار صحیح:

```text
public_html/
├── index.php
├── setup.php
├── database.sql
├── .htaccess
├── admin/
├── assets/
├── includes/
└── uploads/
```

### ۲) ساخت دیتابیس و کاربر

1. در cPanel وارد **MySQL Databases** یا **MySQL Database Wizard** شوید.
2. یک Database بسازید؛ cPanel ممکن است پیشوند حساب را خودکار اضافه کند.
3. یک Database User با رمز بسیار قوی بسازید.
4. User را به Database اضافه کنید.
5. در مرحله Privileges گزینه **ALL PRIVILEGES** را فعال کنید. برای عملکرد پروژه دست‌کم مجوزهای SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX و REFERENCES لازم است.
6. نام کامل دیتابیس، نام کامل کاربر و رمز را در جای امن یادداشت کنید.

### ۳) Import دیتابیس

1. وارد **phpMyAdmin** شوید و دیتابیس ساخته‌شده را از ستون سمت چپ انتخاب کنید.
2. تب **Import** را باز کنید.
3. فایل `database.sql` را انتخاب و Import را اجرا کنید.
4. پس از موفقیت باید جدول‌های `admins`، `categories`، `products`، `settings` و `login_attempts` دیده شوند.

> Import مجدد `database.sql` همه داده‌های جدول‌های پروژه را پاک و از نو ایجاد می‌کند. برای سایت فعال دوباره Import نکنید.

### ۴) تنظیم اتصال

فایل `includes/config.php` را در File Manager ویرایش کنید:

```php
const DB_HOST = 'localhost';
const DB_NAME = 'cpanelprefix_database';
const DB_USER = 'cpanelprefix_user';
const DB_PASS = 'YOUR_STRONG_DATABASE_PASSWORD';
```

در بیشتر هاست‌ها `DB_HOST` همان `localhost` است. اگر شرکت هاست مقدار دیگری داده، همان را وارد کنید. رمز دیتابیس هرگز نباید در چت، اسکرین‌شات یا مخزن عمومی قرار گیرد.

اگر پروژه در ریشه دامنه است `BASE_URL` را خالی بگذارید. اگر در زیرپوشه نصب شد، مثلاً:

```php
const BASE_URL = '/menu';
```

### ۵) ساخت مدیر اولیه

1. پس از Import و تنظیم اتصال، آدرس `https://miracafe.ir/setup.php` را باز کنید.
2. نام کاربری و رمزی حداقل ۱۲ کاراکتری شامل حرف و عدد بسازید.
3. پس از پیام موفقیت، وارد `https://miracafe.ir/admin/` شوید.
4. **فوراً فایل `setup.php` را از public_html حذف کنید.** حتی اگر صفحه پس از ساخت اولین مدیر غیرفعال می‌شود، حذف فایل لایه امنیتی بهتری است.

هیچ رمز خام یا مدیر پیش‌فرضی در کد و دیتابیس وجود ندارد.

### ۶) SSL و HTTPS

1. در cPanel بخش **SSL/TLS Status** یا **AutoSSL** را باز کنید.
2. بررسی کنید گواهی دامنه `miracafe.ir` فعال و معتبر باشد.
3. `https://miracafe.ir` را باز کنید و وجود علامت قفل را بررسی کنید.
4. فایل `.htaccess` درخواست‌های غیرمحلی HTTP را به HTTPS هدایت می‌کند.

### ۷) دسترسی پوشه‌ها

- پوشه‌ها: معمولاً `755`
- فایل‌ها: معمولاً `644`
- پوشه `uploads`: ابتدا `755`; فقط اگر هاست اجازه نوشتن نداد `775` را امتحان کنید.
- از `777` استفاده نکنید.

فایل `uploads/.htaccess` اجرای PHP و فایل‌های اجرایی/HTML/SVG را در پوشه آپلود مسدود می‌کند. آن را حذف نکنید.

## استفاده از پنل

- ورود: `https://miracafe.ir/admin/`
- محصول‌ها: افزودن، ویرایش، حذف، قیمت، ترتیب، موجودی و نمایش/مخفی
- دسته‌ها: افزودن، ویرایش، فعال/غیرفعال و ترتیب
- تنظیمات: نام کافه، عنوان صفحه، اینستاگرام، تماس، آدرس و رفتار محصولات ناموجود
- تغییر رمز: بخش «رمز عبور» در پنل

حذف دسته‌ای که محصول دارد عمداً مسدود است. ابتدا محصولات آن را به دسته دیگر منتقل یا حذف کنید.

## QR Code

QR باید فقط این نشانی ثابت را داشته باشد:

```text
https://miracafe.ir/
```

می‌توانید در مرورگر Chrome صفحه را باز کنید و از گزینه **Create QR Code for this page** استفاده کنید، یا با یک QR ساز رایگان و آفلاین همین URL را تبدیل کنید. پیش از چاپ، QR را با iPhone و Android تست کنید. چون QR فقط URL را نگه می‌دارد، تغییر قیمت‌ها یا آیتم‌ها نیاز به چاپ دوباره ندارد.

## نسخه پشتیبان

### دیتابیس

در phpMyAdmin دیتابیس را انتخاب کنید، **Export** → حالت Quick → فرمت SQL را بزنید و فایل را در جای امن نگه دارید.

### تصاویر

در File Manager پوشه `uploads` را Compress و فایل ZIP را دانلود کنید. بهتر است پیش از تغییرات بزرگ و دست‌کم هفتگی از دیتابیس و تصاویر نسخه پشتیبان بگیرید.

## کارهای ضروری پس از نصب

- فایل `setup.php` را حذف کنید.
- فایل `database.sql` را از `public_html` حذف یا به محل غیرعمومی منتقل کنید؛ `.htaccess` دسترسی وب را مسدود کرده، اما حذف بهتر است.
- رمز cPanel و دیتابیس را با رمز مدیر سایت یکسان انتخاب نکنید.
- یک محصول آزمایشی و تصویر کوچک بارگذاری کنید و نمایش موبایل را بررسی کنید.
- از بخش تنظیمات، شماره تماس، اینستاگرام و آدرس را تکمیل کنید.
- خطاهای PHP را در سایت عمومی نمایش ندهید؛ در cPanel گزینه `display_errors` باید Off و ثبت خطاها On باشد.

## تغییر رنگ و فونت

رنگ‌های برند در ابتدای `assets/css/style.css` با متغیرهای زیر هستند:

```css
--color-pink: #B56E6F;
--color-turquoise: #588D88;
--color-background: #F5F1EB;
--color-light-pink: #EBD3C4;
--color-text: #34443D;
```

رنگ آبی مکمل برند نیز با متغیر `--mira-blue: #4F748A` تعریف شده است.

برای فونت محلی، فایل WOFF2 را در `assets/fonts` بگذارید، یک `@font-face` به CSS اضافه کنید و مقدار `--font` را تغییر دهید. فقط وزن‌های واقعاً لازم را اضافه کنید.

## عیب‌یابی کوتاه

- پیام اتصال: نام دیتابیس، کاربر، رمز و Host را در `includes/config.php` بررسی کنید.
- خطای 500: نسخه PHP را روی 8.1+ بگذارید و Error Log cPanel را ببینید.
- آپلود انجام نمی‌شود: permission پوشه `uploads`، محدودیت `upload_max_filesize` و فعال بودن `fileinfo` را بررسی کنید.
- لینک‌ها غلط‌اند: مقدار `BASE_URL` را مطابق محل نصب تنظیم کنید.
- تغییرات CSS دیده نمی‌شود: کش مرورگر یا کش cPanel/CDN را پاک کنید.
